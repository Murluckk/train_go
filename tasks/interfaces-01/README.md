# io.Writer со счётчиком

Реализуй обёртку над `io.Writer`, которая считает, сколько байт и строк
через неё прошло:

```go
type CountingWriter struct {
	// поля на твоё усмотрение
}

func NewCountingWriter(w io.Writer) *CountingWriter
func (c *CountingWriter) Write(p []byte) (int, error)
func (c *CountingWriter) Bytes() int64
func (c *CountingWriter) Lines() int64
```

## Требования

- `CountingWriter` должен удовлетворять `io.Writer`. В тестах есть
  проверка присваивания на этапе компиляции.
- `Write` возвращает ровно то, что вернул нижележащий writer — и число
  байт, и ошибку. Не «исправляй» короткую запись.
- Счётчики увеличиваются на **фактически записанное** число байт.
  Если нижележащий writer записал 3 байта из 10 и вернул ошибку,
  засчитываем 3.
- `Lines()` — количество символов `\n` среди фактически записанных байт.
  Последняя строка без перевода строки не считается.
- Нулевое значение счётчиков — 0, отдельная инициализация не нужна.

## Где обычно ошибаются

`io.Writer` по контракту обязан вернуть ошибку, если записал меньше
`len(p)`. Обёртка не должна этот контракт нарушать и не должна его
чинить за нижележащий writer.
