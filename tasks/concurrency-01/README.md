# Параллельный Map с WaitGroup

Реализуй:

```go
func ParallelMap(xs []int, f func(int) int) []int
```

Применяет `f` к каждому элементу в отдельной горутине и возвращает
результаты **в исходном порядке**.

## Требования

- Каждый элемент обрабатывается в своей горутине.
- Порядок результатов соответствует порядку входа.
- Никаких гонок: тесты гоняются с `-race`.
- `ParallelMap(nil, f)` возвращает `nil`.
- `f` вызывается ровно по одному разу на элемент.

## Где обычно ошибаются

Классика — писать результаты через общий слайс с `append` из нескольких
горутин. Второй классический способ выстрелить себе в ногу — захватить
переменную цикла (начиная с Go 1.22 это уже не проблема, но привычка
передавать индекс параметром всё равно полезна).

Подсказка: если у каждой горутины свой индекс в заранее выделенном
слайсе, мьютекс не нужен вообще.
