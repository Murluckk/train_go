# Дженерик Filter и Partition

Реализуй:

```go
func Filter[T any](xs []T, keep func(T) bool) []T
func Partition[T any](xs []T, keep func(T) bool) (yes, no []T)
func Count[T any](xs []T, keep func(T) bool) int
```

## Требования

- `Filter` возвращает новый слайс с элементами, для которых `keep`
  вернула `true`, порядок сохраняется.
- Если подошедших элементов нет — возвращается `nil`, а не пустой слайс.
- `Partition` за один проход делит на подошедшие и не подошедшие;
  каждая половина подчиняется тому же правилу про `nil`.
- Входной слайс не изменяется, и результат не должен делить с ним память.
- `keep` вызывается ровно по одному разу на элемент, в порядке слайса.

## Где обычно ошибаются

`make([]T, 0, len(xs))` — удобно, но тогда пустой результат будет
непустым слайсом, и тест на `nil` покраснеет. Решай, что возвращать, на
выходе, а не на входе.
