# Уникальные значения с сохранением порядка

Реализуй:

```go
func Dedup(xs []string) []string
```

Функция возвращает новый слайс, где каждое значение встречается один раз,
в порядке первого появления во входных данных.

## Требования

- Входной слайс **не изменяется**.
- `Dedup(nil)` возвращает `nil`, а не пустой слайс. Разница между `nil` и
  `[]string{}` здесь проверяется явно — это то место, где легко ошибиться.
- `Dedup([]string{})` тоже возвращает `nil`: если возвращать нечего,
  возвращаем `nil`.
- Пустые строки — обычные значения, их не пропускаем.

## Подсказка по сложности

Ожидаемая сложность — O(n) по времени. Решение на двух вложенных циклах
тесты пройдёт, но это не то, что тренируем.
