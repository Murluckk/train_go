# Инверсия мапы

Реализуй:

```go
func Invert(m map[string]int) map[int][]string
```

Функция меняет ключи и значения местами. Так как разные ключи могут иметь
одинаковое значение, в инвертированной мапе значением становится слайс ключей.

## Требования

- Слайсы ключей отсортированы по возрастанию. Итерация по мапе в Go
  случайна, и без явной сортировки тест будет «иногда зелёный» — это
  главное, что здесь тренируется.
- `Invert(nil)` и `Invert(map[string]int{})` возвращают пустую **не-nil**
  мапу: с ней можно работать сразу, не проверяя на nil.
- Входная мапа не изменяется.

## Пример

```go
Invert(map[string]int{"a": 1, "b": 2, "c": 1})
// map[int][]string{1: {"a", "c"}, 2: {"b"}}
```
