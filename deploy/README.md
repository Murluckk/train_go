# Установка на сервер

## Сначала о безопасности

drill по устройству не имеет аутентификации и по HTTP компилирует и запускает
произвольный код — в этом вся его работа. На сетевом интерфейсе это удалённое
выполнение кода под тем пользователем, от которого запущен сервис.

Поэтому юнит слушает **только 127.0.0.1**, а доступ идёт SSH-туннелем. Снаружи
порт не виден вообще, в браузере всё выглядит как локальный запуск.

Не меняй `-addr` на `0.0.0.0`. Если нужен доступ без туннеля, ставь перед ним
реверс-прокси с аутентификацией и TLS — но туннель проще и надёжнее.

## Что нужно на сервере

Go-тулчейн: раннер вызывает `go test` для каждого решения, одного собранного
бинаря недостаточно.

```sh
curl -sSL https://go.dev/dl/go1.26.0.linux-amd64.tar.gz | tar -C /usr/local -xz
export PATH=/usr/local/go/bin:$PATH
```

## Установка

```sh
git clone https://github.com/Murluckk/train_go.git
cd train_go
./deploy/install.sh          # от root, из корня репозитория
```

Скрипт собирает бинарь, заводит системного пользователя `drill`, раскладывает
всё по `/opt/drill`, ставит юнит, запускает сервис и ждёт `/readyz`.
Повторный запуск — это и есть выкатка новой версии.

Раскладка:

| путь | что |
|---|---|
| `/opt/drill/drill` | бинарь |
| `/opt/drill/tasks` | задачи, только на чтение для сервиса |
| `/var/lib/drill/drill.db` | база: попытки, повторы, журнал |
| `/var/cache/drill/gocache` | кэш сборки |

## Доступ

Со своей машины:

```sh
ssh -N -L 8080:127.0.0.1:8080 root@78.17.106.90
```

и открывай http://127.0.0.1:8080

Чтобы не набирать это каждый раз, в `~/.ssh/config`:

```
Host drill
    HostName 78.17.106.90
    User root
    LocalForward 8080 127.0.0.1:8080
```

тогда достаточно `ssh -N drill`.

## Обслуживание

```sh
systemctl status drill
journalctl -u drill -f          # логи JSON-структурированные
systemctl restart drill
```

Задачи можно править прямо на сервере — drill пересканирует `/opt/drill/tasks`
в течение двух секунд, перезапуск не нужен:

```sh
rsync -a tasks/ root@78.17.106.90:/opt/drill/tasks/
```

База переживает переустановку: она лежит вне `/opt/drill`. Бэкап — это копия
одного файла:

```sh
scp root@78.17.106.90:/var/lib/drill/drill.db ./drill-backup.db
```

## Если что-то не поднялось

`journalctl -u drill -n 50` покажет причину. Самое частое — не найден
Go-тулчейн: тогда самопроверка на старте падает с внятным сообщением, а не
превращается в «у меня почему-то ничего не компилируется» при первом решении.
